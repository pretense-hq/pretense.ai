Trust at Pretense

Pretense runs on your machine. This page states what leaves it, what stays, and which services handle data around it.

How Pretense handles your data

Pretense mutates detected values into deterministic stand-in tokens before a prompt leaves the machine, so the AI provider receives stand-ins in place of them. Secrets, SSNs and card numbers are always mutated. Email addresses and phone numbers are mutated under every framework profile except PCI, and anywhere they are labeled. Without a profile, or under PCI, unlabeled email addresses and phone numbers leave the machine as written.

Code identifiers (function names, variables, symbols) are tokenized on the way out and come back byte-exact in the reply. An identifier inside the model's thinking block stays a stand-in, because that signed block passes through unchanged. Secret and PII tokens are never reversed, by design. A hostile model reply therefore carries only stand-in tokens for every detected credential.

Root certificates and TLS

Pretense never intercepts TLS. Your AI tools reach it through a local base URL, so it installs no root certificate.

Certifications and compliance presets

Pretense ships compliance presets mapped to SOC 2, ISO 27001 and CMMC L2 detector sets. A preset is a set of detectors, and an audit report is a separate document.

No SOC 2 report and no HIPAA certification have been issued to Pretense.

Security contact

Email jimmy@pretense.ai to report a vulnerability. The machine-readable file is at https://www.pretense.ai/.well-known/security.txt and the policy is at https://www.pretense.ai/security.

Uninstall in 3 commands

The script at https://www.pretense.ai/uninstall.sh runs exactly 3 commands in this order. The script deletes no files itself.

Steps 1 and 2 are skipped when the installed version has no always-on service. A binary placed by the curl installer stays at ~/.local/bin/pretense until you remove it with rm.

  1. pretense start --uninstall
  2. pretense start --shell-setup --remove
  3. npm rm -g @pretense/cli
