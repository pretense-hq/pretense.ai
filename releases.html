Releases

Pretense CLI binaries with SHA-256 checksums for every version. The npm package carries the current release. The curl installer uses npm when Node is present and installs the standalone binary otherwise. The standalone binaries below can trail npm.

npm i -g @pretense/cli
curl -fsSL https://www.pretense.ai/install.sh | sh
irm https://www.pretense.ai/install.ps1 | iex
