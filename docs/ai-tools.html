AI coding tools

Guard AI CLIs. Secrets, SSNs and card numbers are always mutated. Email and phone numbers are mutated when labeled and under every framework profile except PCI.

How do I use Pretense with Claude Code, Gemini CLI and Codex?

Install Pretense, sign in, and start the always-on proxy. Your AI command-line tools then send their prompts through Pretense on your machine. Detected secrets, SSNs and card numbers always leave as stand-in tokens, email addresses and phone numbers do under every framework profile except PCI and anywhere they are labeled, and your code comes back exactly as you wrote it.

4 commands

bash
npm i -g @pretense/cli
pretense login
pretense start --install
pretense status

To install without npm, run curl -fsSL https://www.pretense.ai/install.sh | sh.

  1. Install. Use npm (Node 18 or later) or the curl installer.
  2. Sign in. pretense login opens the sign-in page. To sign in from a script, use pretense login --api-key <key>.
  3. Start. pretense start --install keeps the proxy running at login and points your shell at it. Open a new terminal afterwards. To mutate unlabeled email addresses and phone numbers as well, add a framework profile other than PCI: run pretense run claude --framework <profile>.
  4. Check. pretense status checks protection with a canary secret and prints protection=on. To check a proxy that was started with a profile, run pretense status --framework <profile> with the same profile. It checks the proxy in the pid record and the routing of the terminal it runs in. A separate proxy that pretense run starts for a different policy is left unchecked.

What leaves your machine

  • Secrets, SSNs and card numbers: they are always mutated into stand-in tokens before the request goes out. They stay tokens in the reply, by design.
  • Email addresses and phone numbers: Pretense mutates email addresses and phone numbers under every framework profile except PCI (`pretense run claude --framework <profile>`) and anywhere they are labeled. Without a profile, or under PCI, unlabeled email addresses and phone numbers leave your machine as written.
  • Code identifiers: they are swapped on the way out and come back byte-exact in the reply. An identifier inside the model's thinking block stays a stand-in, because that signed block passes through unchanged.
  • The rest of the prompt: it goes to the provider you chose.
  • Usage counts: they go to your Pretense dashboard.

Uninstall

Run curl -fsSL https://www.pretense.ai/uninstall.sh | sh. The script prints each step, removes only what Pretense installed and exits with an error code if a step fails. To do it by hand, run these 3 commands in order.

bash
pretense start --uninstall
pretense start --shell-setup --remove
npm rm -g @pretense/cli

The curl installer places pretense in ~/.local/bin. After the 3 commands, delete ~/.local/bin/pretense to finish.

FAQ

Do I still need pretense run claude?

Only for a single session without the always-on proxy. After pretense start --install, run claude as usual.

Does Pretense install a root certificate?

No. Pretense is a local proxy your tools reach through a base URL, and it never intercepts TLS.

How do I undo it?

Run pretense start --uninstall, then pretense start --shell-setup --remove, then npm rm -g @pretense/cli.
