CLI reference

Every command the shipped binary accepts and what it returns.

Commands

Some take a path, a few a subcommand of their own.

bash
pretense scan .
pretense scan ci

pretense start

pretense start runs the Pretense proxy on your machine. It filters the traffic of AI tools that you route to it with a base URL: ANTHROPIC_BASE_URL and GOOGLE_GEMINI_BASE_URL point at http://127.0.0.1:9339, and OPENAI_BASE_URL and OPENAI_API_BASE point at http://127.0.0.1:9339/v1. A tool that reads one of those variables sends its prompts through the proxy, where detected secrets, SSNs and card numbers become stand-in tokens before the request leaves.

Scope: AI tool traffic that reaches the local proxy

Pretense is a local proxy that your tools reach through a base URL. It works on the requests those tools send to it, and it leaves the rest of the device alone: it keeps whole-device traffic out of scope, installs no root certificate and never intercepts TLS. See Trust.

Set it up once

bash
pretense start --install
pretense status

--install keeps the proxy running at login and points your shell at it. Open a new terminal afterwards. status prints protection=on when the canary secret was mutated on its way out.

Options

CommandWhat it does
pretense startRun the proxy in this terminal on port 9339. Add -p <port> for another port or --strict-port to refuse a busy one
pretense start --installRegister a user-level service that starts the proxy at login, and point every tool at it (0.6.89+)
pretense start --uninstallRemove that service and restore the routing it wrote (0.6.89+)
pretense start --shell-setupWrite the export block into your shell rc file between pretense markers. Add --remove to undo (0.6.89+)
pretense start --env [shell]Print the export lines for zsh, bash, fish or powershell, and change nothing (0.6.89+)
pretense start --framework <ids>Add framework profiles to this proxy's detector sets: hipaa, gdpr, soc2, nist, iso27001, cmmc, pci
pretense statusCheck protection with a canary secret and print protection=on (0.7.0+)

To see the export lines without changing anything, print them.

bash
pretense start --env
pretense start --env powershell

To undo both the service and the shell block, run these 2 commands.

bash
pretense start --uninstall
pretense start --shell-setup --remove

By operating system

OSWhat --install registersBehavior
macOSA LaunchAgent, ai.pretense.proxy, in ~/Library/LaunchAgentsStarts at login and restarts after a crash
LinuxA systemd user unit, pretense-proxy.service, in ~/.config/systemd/userStarts at login and restarts after a crash. Needs a systemd user session; elsewhere, run pretense start in a terminal and add --shell-setup
WindowsA Task Scheduler task, PretenseDaemonStarts at login and restarts up to 3 times, 1 minute apart, after a failure. For the shell block, run pretense start --env powershell or --shell-setup from PowerShell

Every OS uses the same port, 9339, and the same base URLs. AI coding tools lists the tools tested against them.

Mutating a single file

-i writes the result back to the file instead of printing it. --map <path> chooses where the reversal map is written, and where reverse reads it from.

bash
pretense mutate -i src/config.ts
pretense reverse src/config.ts -i --map ~/.pretense/maps/<hash>.json

mutate prints the second line for you, with the real path filled in.

Keep the map

With no --map given, an in-place mutation writes one into ~/.pretense/maps/ and prints the exact command that restores the file. reverse asks for that map and will not run without it, which is what stops a mutated file becoming an unrecoverable one. See How it works.

Exit codes

The 2 scanning forms report findings with different codes. A gate that checks for the wrong one passes while secrets sit in the diff.

CommandCleanFindings
scan01
scan ci02

Gate on the first. scan ci reads only what git tracks, so it exits 0 with an untracked secret still on disk. Automation has the detail.

Known limits

  • mutate takes a file, not a directory.
  • A directory scan skips .md files. Naming one directly does scan it, so a secret pasted into a README passes a repository scan and fails a scan of that file.
