Enterprise

For teams that need the model to run somewhere they control, and an auditable answer to where their code went.

Enterprise is $99 per seat per month, with a minimum of 50 seats and a maximum of 100. It is sold through sales rather than self-serve checkout, so pricing, term and procurement paperwork are settled with a person before anything is signed.

What is included today

  • ✓Everything in Startup
  • ✓50 seats minimum, up to 100
  • ✓Dedicated support and a named CSM
  • ✓SLA and uptime guarantee
  • ✓Air-gapped mode — prompts and code stay on the local machine

On the roadmap

Listed separately on purpose — these arrive later, and we tick only what ships today.

  • •SAML / SSO (coming soon)

Air-gapped mode

The capability most teams come to Enterprise for. Pretense runs against a model on a runner you control, over loopback, so the prompts and code stay on the machine. It fails closed: without a valid licence every request is refused rather than quietly falling back to a hosted provider. Read the air-gap guide for the setup, the licence step, and the limits — including what still touches the network.

Seats and billing

The 50-seat minimum is enforced at checkout, not inside the licence, so an existing account is never locked out of a feature it already has because of a seat count. Billing is per seat per month. Annual terms are handled through sales rather than published as a rate here.

Talk to sales

Enterprise is not available through self-serve checkout — the plan is provisioned after a conversation, so there is no buy button on this page by design. Contact sales to talk through seats, deployment and procurement. For the technical detail a security review will ask for, see security.
